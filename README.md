# NestMate 🏠
NestMate is a cross-platform mobile flatmate discovery and compatibility application built with **React Native / Expo**, **Firebase Auth & Firestore**, and **Google Maps**.

## Features
- **Interactive Swipe Deck**: Discover potential flatmates with lifestyle match % and distance badges.
- **8-Factor Lifestyle Quiz**: Match on sleep schedules, smoking, diet, apartment setup, and gender preferences with custom dealbreakers.
- **Google Maps Integration**: Pin exact flat locations and compute proximity.
- **Real-Time Chat**: Secure real-time messaging with image attachments and read receipts.
